# Seraina Tscharner & Laurin Wiederkehr – Ice Dance Results

A static website with every competition result of the Swiss junior ice dance couple from season 2024/25 onward: scores, a score progression chart, personal bests, official ISU videos and Instagram posts.

- Data: `data/results.json` (run `./build-data.sh` after editing)
- Update procedure: [UPDATE.md](UPDATE.md)
- Hosted with GitHub Pages; no build step needed.
